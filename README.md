## GitHub Pagesでの公開手順

本サイトは外部APIや動的サーバー不要の純粋な静的サイト（HTML/CSS/JS）のため、GitHub Pagesにそのまま完全無料で公開できます。

1. GitHubで新規リポジトリ（例: `push-web`）を作成します。
2. ローカルのファイルをコミットしてプッシュします：
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Push! website"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
3. GitHubリポジトリの **Settings** > **Pages** に移動します。
4. **Source** で `Deploy from a branch` を選択し、**Branch** を `main` / `/(root)` に設定して「Save」をクリックします。
5. 数分で `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` にてサイトが公開されます。

## VS Codeでの編集・更新方法

### 1. 連絡先メールアドレスの変更
- `index.html` 内の `pushweb77@gmail.com`
- `js/main.js` 内の `const EMAIL_ADDRESS = 'pushweb77@gmail.com';`
を検索・一括置換するだけで変更できます。

### 2. 制作例（実績）の追加
`index.html` の `<!-- 制作実績追加用HTMLテンプレート -->` コメント箇所のコードをコピーして貼り付け、画像と店舗情報を書き換えるだけで簡単に実績カードを追加できます。

### 3. 料金や文言の変更
`index.html` 内の各該当セクション（`id="pricing"`, `id="features"` 等）を直接編集するだけで即時反映されます。
